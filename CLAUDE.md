# صافي (Safi) — Mohamed's personal all-in-one Android app

Kotlin + Jetpack Compose (Material3), Room (KSP), Media3, minSdk 26, targetSdk 35. UI language: Egyptian Arabic (RTL), translated to English/Urdu at display time.

**Start here:** read `ROADMAP.md` — the last section lists what is done, what is WIP (may not compile yet), and the user's pending requests in order.

## Build locally
- Needs Android Studio (bundles the JDK and Android SDK). `local.properties` with `sdk.dir=...` is created when the project is opened once in Android Studio.
- `./gradlew assembleDebug` → `app/build/outputs/apk/debug/app-debug.apk`
- Both debug and release are signed with `app/safi.jks`, so a local build installs over the installed app without losing data.
- Install on a phone: `adb install -r app/build/outputs/apk/debug/app-debug.apk` (USB debugging on), or copy the APK to the phone and open it.

## Rules that matter
- Religious content must be authentic and Sunni only. Never write a hadith from memory: content in `assets/deen/` is generated by `tools/deen/build.py`, which verifies every quote against the six books (sources described in its docstring; set `DEEN_SRC`). Same for the quiz (`tools/quiz/build.py`).
- Every file using Material3 must also `import com.mohamed.safi.ui.Text` (the wrapper that translates via `tr()`).
- New Arabic UI strings: run `python3 tools/i18n_extract.py`, then add en/ur translations to `app/src/main/assets/i18n/{en,ur}.json` (keep `{0}` placeholders).
- Use `Locale.US` for anything stored, parsed, or put in a URL/file name (Arabic digits break parsing). `ui/Digits.kt` shadows `toDoubleOrNull` etc.
- Room has no migrations: new tables go into a new DB file and must be added to `extra/Backup.kt` dbNames.
- UI building blocks live in `ui/Common.kt` (ScreenScaffold, AppCard, GoldCard, SectionTitle, Pill, ChipsRow, DateField, NumberField, ConfirmDialog…); colors in `ui/Theme.kt` (Brand, Gold, Amiri font); reading-comfort mode in `ui/Reading.kt` (wrap reading screens in `ReadingTheme { }` and add `ReadingSettingsButton()`).
- Navigation: string routes in `MainActivity.kt` NavHost; cross-screen jumps via `UiBus.pendingRoute` etc. (`ui/Shared.kt`). New screens also go in `MoreScreen.kt` and the assistant's `open_screen` list in `ai/Assistant.kt`.

## Optional: GitHub CI
`.github/workflows/build.yml` builds on push to `dev`/`main` and runs emulator UI tests (`tools/uitest.py`, `tools/uiplan.json`); merging into `main` publishes a release. `books.yml` converts the library books (`tools/books.json`) into the `books` release the app downloads from. None of this is needed to build locally.
